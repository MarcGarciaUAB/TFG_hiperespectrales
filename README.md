# TFG: Diseño e implementación de una herramienta web para el análisis de imágenes hiperespectrales​.


## Resumen del Proyecto:

Este proyecto tiene como objetivo principal la gestión, procesamiento y visualización de datos provenientes de sensores hiperespectrales. A diferencia de las imágenes tradicionales (RGB), las imágenes hiperespectrales capturan un amplio espectro de bandas de luz para cada píxel, lo que permite extraer información detallada sobre la composición y características de los materiales observados, imperceptibles para el ojo humano.

Para facilitar el análisis de esta compleja información, se ha desarrollado una solución completa de software dividida en dos módulos principales:
- Una **API (Backend)** encargada del procesamiento pesado, almacenamiento y gestión de la lógica de negocio.
- Una **Interfaz Gráfica (Frontend)** interactiva diseñada para la visualización y análisis de los resultados por parte del usuario final.
